
# Проект Базы Данных (DataBase)

Это мой старый университетский проект, улучшенный и доработанный (разделила код, добавила Makefile и README).

---

## Описание

Простой консольный проект базы данных, который позволяет:

- Добавлять записи (Фамилия, Имя, Отчество, Год рождения, ID)
- Удалять запись по ID
- Выводить все записи
- Искать записи по фамилии
- Сортировать записи по ID и по фамилии
- Загружать данные из файла и сохранять их в файл

Проект написан на C++ с использованием классов и STL.

## Сборка и запуск

Для сборки проекта используйте Makefile. Просто выполните в корне проекта команду:

```bash
make
```

В результате будет создан исполняемый файл `my_program`.

Для очистки объекта и бинарника:

```bash
make clean
```

Запустите программу:

```bash
./my_program
```

## Как использовать

Программа предоставляет текстовое меню с выбором действий:

- Добавить запись  
- Удалить запись по ID  
- Показать все записи  
- Поиск по фамилии

- Загрузка и сохранение из/в файл

---

## Формат файла

Данные хранятся в текстовом файле с расширением `.txt` (например, `data.txt`).  
Каждая запись занимает одну строку, поля разделены символом `,` (запятая).

Пример строки:

```
123, Иванов, Иван, Иванович, 1990
```

Где поля по порядку:

- ID (числовой идентификатор)
- Фамилия
- Имя
- Отчество
- Год рождения (четырёхзначное число)

При загрузке и сохранении программа использует этот формат.
